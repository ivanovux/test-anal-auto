# Аналитика цен на авто (MVP)

Веб-приложение: выбираете марку, модель, поколение, комплектацию и период и получаете сводку по ценам с **Drom.ru** и **Auto.ru**: среднюю и медианную цену, минимум и пик за период (со ссылками на объявления), изменение медианы, график по дням, разбивку по площадкам и годам выпуска.

## Откуда берётся история цен

Площадки показывают только текущие объявления, истории цен у них нет. Поэтому:

1. **Сборщик** раз в сутки (по умолчанию в 04:17 МСК) проходит выдачу по *отслеживаемым* моделям и сохраняет снимок цены каждого объявления.
2. **Аналитика за период** строится по этим снимкам. Считается, что объявление продаётся с первого до последнего дня, когда мы его видели. Между снимками действует последняя известная цена.
3. **Оценка прошлого.** Опция «Достраивать историю по дате публикации» продлевает каждое объявление назад до даты публикации с первой увиденной ценой. Так история есть сразу после первого сбора. Эти дни на графике показаны пунктиром.

Чем дольше работает сборщик, тем точнее аналитика.

## Быстрый старт

```bash
cp .env.example .env
docker compose up -d --build
# открыть http://localhost:8000
```

Без Docker:

```bash
pip install -r requirements.txt
python -m app.cli init
python -m app.cli collect --model camry --pages 2   # разовый сбор
uvicorn app.main:app --port 8000
```

Демо-данные (синтетика, чтобы посмотреть интерфейс):

```bash
python -m app.cli demo           # создать (источники «drom-demo», «autoru-demo»)
python -m app.cli demo --clear   # удалить
```

## Как пользоваться

- В блоке «Сбор данных» отметьте **«Отслеживать модель ежедневно»**: модель попадёт в ежедневный сбор. Кнопка **«Собрать сейчас»** запускает сбор сразу.
- **Комплектация** — модификация, собранная из параметров объявления: объём, мощность, топливо, КПП и привод. В списке только те, что встречались в собранных объявлениях.
- **Поколение** определяется по коду кузова с площадки (aliases в каталоге), а если его нет — по году выпуска.
- **Выбросы** (цены за пределами 1.5×IQR) по умолчанию исключаются. Цены ниже `MIN_VALID_PRICE` (50 000 ₽) отбрасываются ещё при сборе.
- **CSV** — выгрузка дневной статистики.

## Каталог

`data/catalog.json` содержит марки, модели, поколения и пути на площадках:

- `drom_path` — путь на auto.drom.ru (`toyota/camry`);
- `autoru_mark` / `autoru_model` — коды auto.ru (`TOYOTA` / `CAMRY`);
- `aliases` — названия поколений на площадках.

Чтобы добавить модель, допишите её в файл и перезапустите приложение.

## Обход блокировок

- Запускайте на ПК или VPS с **российским IP**.
- Скорость сбора задаётся задержками `REQUEST_DELAY_MIN/MAX` между запросами (по умолчанию 2–5 с). Уменьшать их не советую.
- **Auto.ru** часто показывает капчу. В этом случае запуск получает статус `blocked`. Решение: войдите на auto.ru в браузере, скопируйте заголовок `cookie` (DevTools → Network) в `AUTORU_COOKIES` в `.env`. Можно также указать прокси в `SCRAPER_PROXY`.
- Если площадка поменяла вёрстку, поправить нужно только парсер в `app/scrapers/drom.py` или `app/scrapers/autoru.py`. Тесты на фикстурах лежат в `tests/`.

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SOURCES` | `drom,autoru` | площадки |
| `MAX_PAGES` | `5` | страниц выдачи на модель (≈20 объявлений на странице) |
| `COLLECT_HOUR`, `COLLECT_MINUTE` | `4`, `17` | время ежедневного сбора (МСК) |
| `REGION_DROM` | пусто = вся РФ | поддомен drom: `moscow`, `spb`… |
| `REGION_AUTORU` | `rossiya` | регион auto.ru: `moskva`, `sankt-peterburg`… |
| `DATABASE_URL` | SQLite в `data/app.db` | можно указать PostgreSQL |

## Структура

```
app/
  scrapers/      парсеры Drom и Auto.ru
  collector.py   сохранение объявлений и снимков цен
  analytics.py   расчёт сводки за период
  catalog.py     каталог и определение поколения
  main.py        API (FastAPI) + планировщик
  static/        веб-интерфейс (Chart.js)
tests/           pytest: парсеры, аналитика, API
```

Запуск тестов: `python -m pytest`.
